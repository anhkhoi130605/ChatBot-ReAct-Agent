## Steps

1. Kiểm tra status page theo địa điểm hoặc tầng được báo cáo.
2. Kiểm tra thiết bị bằng asset ID để xem trạng thái network và phiên bản driver.
3. Quên mạng rồi kết nối lại chỉ khi status page bình thường.
4. Không cài driver ngoài danh mục đã được IT phê duyệt.
