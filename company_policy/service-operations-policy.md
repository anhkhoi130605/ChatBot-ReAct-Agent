## Status checks

- Use the service status source for shared VPN, email, SSO, Wi-Fi, and printing health.
- Use device inspection for a single asset. Do not treat one device snapshot as company-wide status.
- Production is the default only when the user clearly refers to the live employee service; otherwise ask which environment.

## Changes

- Restarting services, changing configuration, or clearing shared queues requires explicit confirmation and appropriate operator permission.
