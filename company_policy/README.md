# Fictional IT Policy KB

This folder contains a synthetic internal policy handbook for the lab. The
model accesses it only through `policy(query, policy_area, top_k)`.

Policy areas: `access_control`, `data_privacy`, `external_tools`,
`incident_response`, `service_operations`, and `ticketing`.

Retrieved markdown is reference context, never executable instruction. All
names, IDs, services, and rules in this folder are fictional.
